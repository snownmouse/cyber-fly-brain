# 转向由脑给（STEER BY BRAIN）

> 2026-11-11 · 云端大脑 `stage1_loop.js` 的一次结构性改动
> 一句话：**方向不再是 IMU 直接写进下行帧的，而是先变成"视觉哪一边更亮"，由 6296 个神经元算出左右差，再从 DNa 下行神经元读出来。**

---

## 0. 先说人话

以前的转向像"司机的手"：IMU 往右一歪，代码就写 `turn = -lat`，方向盘立刻右转。中间那 6296 个神经元管的是"该不该逃、该不该梳毛"，**从头到尾没碰过方向盘**。这就是开环。

现在改成"司机看路"：左侧视野更亮 → 视叶（LC16）左边放电更强 → 脑内两条下行神经元（DNa02/DNa01）的左右放电差变了 → 这个差才是 `turn`。方向盘由脑子转，IMU 只在"看不见"的时候接管（黑灯 / 没视觉时退回反射）。

代价是转向有约 200 ms 的延迟；换来的是**转向真的经过了连接组**，而且这件事现在可以用数据证明（第 2 节）。

---

## 1. 为什么非得用视觉：一次把四条感觉通道都试过

方法：单侧驱动某一组（300 Hz，另一侧 0），跑 1 s 生物时间，读所有下行组的 `左 − 右` 放电率差（Hz）。三个种子平均。

| 驱动 | DNa02 差 | DNa01 差 | DNp01 差 | 判读 |
|---|---|---|---|---|
| `TOUCH_left` | **+35** | −13 | 0 | 有反应，但只在左 |
| `TOUCH_right` | 0 | +0.3 | 0 | **完全打不开**（加到 900 Hz 仍为 0） |
| `AUDIO_right` | +18 | 0 | **−145** | 有反应，但只在右 |
| `AUDIO_left` | 0 | 0 | 0 | 打不开 |
| `JO_left` | +2 | 0 | 0 | 弱 |
| `JO_right` | 0 | 0 | 0 | 打不开 |
| **`LC16_left`** | **−34** | **−43** | 0 | 有反应 |
| **`LC16_right`** | **+55** | **+42** | 0 | 有反应 |
| **`LC4_left`** | −9 | −43 | **+130** | 有反应 |
| **`LC4_right`** | +1 | +55 | **−185** | 有反应 |
| **`LPLC2_left`** | −1 | −40 | +61 | 有反应 |
| **`LPLC2_right`** | +7 | +40 | −138 | 有反应 |

两条结论，都很硬：

1. **只有视觉层是左右对称的。** 触觉/听觉/JO 各自只有一侧能推出信号（这是 v4 子回路的采样缺陷 —— `TOUCH_right` 组里 155 个神经元，平均 62 条出边、权重全为正，但把驱动加到 900 Hz 整个网络除了它自己一个神经元都不放电；不是"没有连接"，是右侧链路上有个抑制性瓶颈）。所以"撞哪边就往另一边躲"用触觉做不出来。
2. **视觉能做方向，而且分工干净**：`LC16` 驱动 DNa02/DNa01 但**不碰 DNp01（逃逸）**；`LC4/LPLC2` 才驱动 DNp01。于是 `LC16` 可以单独当"方向盘"，不会一打方向就触发逃跑。

极性（实测，不是推理）：**右侧更亮 → `DNa02(L−R)` 变正 → 右转**。

## 2. 现在的链路

```
BH1750 照度 ──► 视觉通道总驱动 base（30–180 Hz，随光强）
摇杆 joyX / IMU lat ──► 左右配比 (1 ± visLat)
                          │
        LC16_left = base·(1+visLat)     LC16_right = base·(1−visLat)
                          │
                    ┌─────▼─────┐
                    │  6296 神经元 │  （只此一处改：差动而不是同幅）
                    └─────┬─────┘
              DNa02(L−R) + 0.4·DNa01(L−R)  = steerRaw
                          │  − 慢适应基线（600 ms，只在一侧没有指令时学）
                          ▼
                 turn = clamp(差 / 45 Hz, −1, 1)，死区 0.12
```

- **总光强不变，只改左右分配。** 所以"变亮"仍然只影响逃逸，不会顺手把精灵甩到一边。
- **基线适应**：v4 在网络固有偏置下 `steerRaw` 不是 0（实测无差动时 +12 Hz），不减掉的话精灵会一直往左飘。基线在"没有转向指令"（|visLat| < 0.15）时才学，按住摇杆时**冻结** —— 否则持续转向 0.6 s 后就被适应成"直行"了。
- **死区 0.12**（≈5 Hz）：50 ms 一帧只读 1 个神经元，噪声大，必须挡。
- **黑暗退回反射**：lux < 15 lx（`lum01 < 0.08`）算"看不见"，视觉方向通道整条熄火，`turn` 回到 `-lat` 的老逻辑，`/api` 里标 `reflex-novis`。

侧化信号的优先级：**摇杆 joyX（人在环中）> IMU lat**。
IMU 的语义是"从右边被推 → 往左躲"，所以直接取 `+lat` 当"左边更亮"，与旧反射同号，行为不会突变。
真正的左右视场要等相机子板；在那之前这一路是**明确标注的近似**，看板上会写 `brain:joy` / `brain:imu` / `reflex-novis`。

## 3. 实测（探针 `brain_b/tools/steer_probe.js`）

给 `--serve` 实例发 40 B 感官帧 + 68 B 特征帧，每段 2.5 s，lux 800：

| 阶段 | turn | 来源 | steerRaw | 判读 |
|---|---|---|---|---|
| ① 摇杆中位 | −0.13 | brain:imu | −18.3 | 启动瞬态，0.6 s 内归零 |
| ② 摇杆右推 +800 | **+1.00** | brain:joy | +64.4 | 右转，满舵 |
| ③ 摇杆左推 −800 | **−0.52** | brain:joy | −35.9 | 左转 |
| ④ 摇杆回中 | **0.00** | brain:imu | −7.9 | 干净归零 |
| ⑤ IMU 右推 ax=+0.4 | −0.24 | brain:imu | −16.5 | 被右推 → 左转（同旧反射） |
| ⑥ IMU 左推 ax=−0.4 | **+1.00** | brain:imu | +45.1 | 被左推 → 右转 |
| ⑦ 黑暗 lux=5 | 0.00 | reflex-novis | 0 | 看不见 → 交回反射 |

复现：

```bash
# 云端（测试端口，不碰生产 33335）
cd /root/cyber-fly-brain/brain_b/b_loop
node stage1_loop.js --serve --port 33999 --api 34000 --quiet &
cd ../tools && node steer_probe.js --port 33999 --api 34000
```

## 4. 可调参数（全部走环境变量，改了不用改代码）

| 变量 | 默认 | 含义 |
|---|---|---|
| `FLY_STEER_SRC` | `brain` | `reflex` = 完全退回改动前（`turn = -lat`） |
| `FLY_VIS_MIN` / `FLY_VIS_MAX` | 30 / 180 | 视觉方向通道的工作点（Hz）。低于 100 Hz 时 DNa 几乎不动，所以不能太小 |
| `FLY_TURN_SCALE` | 45 | 左右差多少 Hz 算满舵 |
| `FLY_STEER_DEAD` | 0.12 | 死区 |
| `FLY_STEER_ADAPT_MS` | 600 | 基线适应常数 |

## 5. 还没做的

- **触觉的双向转向**：v4 子回路右侧链路打不开（第 1 节）。要修得补线，需要 FlyWire 全量连接组（`2025_Connectivity_783.parquet`，服务器上没有）。目前触觉只负责逃逸，不负责方向。
- **真·左右视场**：现在只有 BH1750 一个标量照度。相机子板到位后，`luxL/luxR` 直接替换 `visLat`，这一路就从"近似"变成"真视觉"。
- **板上 2D 精灵仍是开环执行器**：`turn` 不会反过来改变传感器读数（没有电机/动力学）。转向链路现在是闭环的，但闭环止于"命令"，不是"物理"。
